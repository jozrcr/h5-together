**open-homm5 0.2.7** brings back Tribes of the East's start bonuses, lets MMH5.5's scripts run on random maps in multiplayer, and adds a switch to unlock each class's skills. All three are in the host's "Game rules" menu, chosen for each game. The installer now also updates your settings file. It is one file, `dinput8.dll`, plus a settings file and 24 ready random map templates; the game's own files are never changed. You need the game with **MMH5.5 already installed** (RC19d or RC19k).

## New in 0.2.7

All of these are in the host's **Game rules** menu (**"Règles..."** or **F2** in the multiplayer waiting room). Each one starts on what MMH5.5 does today.

- **Tribes of the East start bonuses.** With **"ToE start bonuses"** on, each player keeps the bonus they pick with the lobby arrows: gold, resources, an artifact, or random, as in the original game. The lobby shows ToE's own bonus icons and tooltips again (MMH5.5 had painted its game modes over them). MMH5.5's replacement artifact is not given on top.
- **Game mode, chosen on its own.** **Default**, **Savage**, **Nightmare** or **Random** (drawn at the start), or **Bonus arrows** to keep MMH5.5's way of picking the mode with the bonus arrows. Savage and Nightmare work as before.
- **MMH5.5 scripts on random maps.** Until now, on maps made by the game's random generator, MMH5.5's scripts (governors, the computer's weekly bonus, mixed stacks, game modes...) did not run in multiplayer on RC19d, so the other game rules did nothing there. With this switch on, they run, on every PC. It starts off on RC19d and on on RC19k, which is what each version does by itself.
- **Skills of each class.** **MMH5.5 (locked)** keeps each class to its own skills. **Unlocked** keeps those at their usual chances and adds every other skill at a small chance, like in the original game, where any hero could sometimes be offered any skill. Witch huts and the skill wheel pages still follow MMH5.5's classes. Saved games keep this choice.
- **The installer updates `open-homm5.ini`.** It keeps every value you set, adds the new settings with their explanations, and saves your old file as `open-homm5.ini.bak` (the last three are kept). It ends with a line such as "settings file refreshed: 12 of your settings kept, 5 new settings available".

**Everyone needs 0.2.7** for these rules. If a player has an older version or no add-on, the host's menu shows who, and those rules stay as MMH5.5 does them.

## Install

1. Download `open-homm5-0.2.7.zip` below and extract it.
2. Install:
   - **Windows:** double-click `install.bat`.
   - **Linux (Steam / Proton):** run `bash install.sh` and paste the line it prints into the game's Steam launch options.
3. **Everyone in the same co-op game should install this version.**

## Check that it works

- The first line of `open-homm5.log` (in the game's `bin` folder) says `open-homm5 hook DLL 0.2.7 loaded`.
- The host's Game rules menu has a group **"Heroes and skills"**.

## Good to know

- **Loading a multiplayer save** with these rules has not been tested yet. Every player needs the add-on for it.
- **If a game freezes,** wait 30 seconds before closing it, then send `open-homm5.log`.
- **Uninstall:** `uninstall.bat` (Windows) or `bash uninstall.sh` (Linux).
