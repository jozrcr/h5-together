**open-homm5 0.2.6** adds a "Game rules" menu for the host, so MMH5.5's switches are chosen for each game and sent to every PC, and makes hero looks show on the hero screen right away. It is one file, `dinput8.dll`, plus a settings file and 24 ready random map templates; the game's own files are never changed. You need the game with **MMH5.5 already installed** (RC19d or RC19k).

## New in 0.2.6

- **Game rules, chosen by the host for each game.** In the multiplayer waiting room, the host clicks **"Règles..."** (or presses **F2**). The menu has MMH5.5's switches, each with a one-line explanation:
  - governors, town conversion (and how many), the town gate, mine guards, dimension doors;
  - the computer's weekly bonus, prank artifacts, mixed neutral stacks;
  - the random-map extras and potions.

  It starts from your own MMH5.5 settings file; anything you change shows in gold. When the game starts, every PC plays with the host's rules, so nobody swaps files anymore. Friends see the rules in the lobby and during the game. The host's last choices are remembered.
  - **Everyone needs 0.2.6.** If a player doesn't have it, the rules are not sent, everyone uses their own MMH5.5 file as before, and the host's menu shows who is missing.
  - **Good to know:** on random maps made by the game's generator, MMH5.5's scripts (governors, weekly bonus, mixed stacks...) don't run in multiplayer, so these rules change nothing there yet. A switch for that is on the way.
- **Hero looks show at once on the hero screen.** After **Appliquer**, the hero screen closes and reopens on the same page with the new 3D figure, the way you'd do it by hand. `[skins] live_hero_screen=0` turns this off.

## Install

1. Download `open-homm5-0.2.6.zip` below and extract it.
2. Install:
   - **Windows:** double-click `install.bat`.
   - **Linux (Steam / Proton):** run `bash install.sh` and paste the line it prints into the game's Steam launch options.
3. **Everyone in the same co-op game should install this version.**

The installer keeps your `open-homm5.ini`. New settings work without being in it.

## Check that it works

- The first line of `open-homm5.log` (in the game's `bin` folder) says `open-homm5 hook DLL 0.2.6 loaded`.
- In the multiplayer waiting room, the host sees a **"Règles..."** button.

## Good to know

- **If a game freezes,** wait 30 seconds before closing it, then send `open-homm5.log`.
- **Uninstall:** `uninstall.bat` (Windows) or `bash uninstall.sh` (Linux).
